Jerry is a personal AI assistant designed to be used in everyday life through an Android application. It should understand natural-language requests, work with connected services, manage personal tasks and reminders, and perform supported actions with appropriate user authorization.
The goal is to build Jerry incrementally: first as a reliable AI chat application, then as a connected assistant, and finally as a secure, context-aware assistant capable of carrying out useful workflows.

The app is currently in first phase with just ui design
phase 2: manual task, calender, and alarm management
phase 3: automated management using API
phase 4: self trained ai model for automation
phase 5: Home automation and IOT integration with hybrid model using both api keys and own ai model.
